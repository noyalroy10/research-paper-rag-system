# Research Paper RAG System

AI-powered research paper summarization and question answering system built with Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG), with a Gradio interface.

## What it does
- Takes a research paper (PDF) as input
- Splits it into chunks and converts them into embeddings
- Retrieves the most relevant sections for a question
- Generates grounded summaries and answers using an LLM

## Tech stack
- Python
- LLM + RAG pipeline
- Gradio (web interface)
- Google Colab / Jupyter Notebook

## How to run
1. Download `Research_Paper_RAG_System.ipynb`
2. Open it in Google Colab or Jupyter Notebook
3. Run all cells in order
4. Open the Gradio link that appears, upload a paper, and ask questions
